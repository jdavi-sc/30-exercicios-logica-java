## 📄 Descrição

Este projeto tem como objetivo apresentar a resolução de uma lista com **30 questões de lógica de programação**, todas desenvolvidas em **Java**. A proposta visa fortalecer o raciocínio lógico e a habilidade de solucionar problemas de forma estruturada e eficiente, utilizando os principais conceitos da linguagem.
